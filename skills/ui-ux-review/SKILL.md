# Skill: UI/UX Review

## Goal

Review interfaces against the Franchise Dekho editorial + enterprise
design policy. Do not equate visual novelty with quality.

## Inspect

-   User, task and primary action.
-   Information hierarchy and reading order.
-   Typography, line length, spacing, grid and alignment.
-   Component consistency and purposeful variation.
-   Content accuracy, verification evidence and uncertainty.
-   Mobile-specific composition and responsive breakpoints.
-   Keyboard flow, focus, contrast, labels and error messaging.
-   Loading, empty, disabled, success and recovery states.
-   Performance, image relevance and reduced motion.
-   Reuse of existing components/tokens.

## Reject

-   Repetitive card grids without a content reason.
-   Gratuitous gradients, shadows, blobs, glassmorphism or animations.
-   Decorative icons with no semantic purpose.
-   Fake ratings, reviews, claims or trust badges.
-   Tiny low-contrast text or forms that ask for unnecessary data.
-   A visually polished page with nonfunctional controls.

## Review output

For each issue state: severity, screen/component, user impact, evidence,
proposed fix and whether it is in the current task scope. Fix
high-impact issues first. Do not redesign unrelated screens.
